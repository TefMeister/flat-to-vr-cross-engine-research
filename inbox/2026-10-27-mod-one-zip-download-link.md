# A one-zip download link on the front page

Tefa asked (2026-10-27) that every tool and library of ours can be downloaded on its own, without Lanes. The
toolkit, the control profiles, BeG0nE and the terminal themes now carry a "Download" section near the top of their
README linking to `https://github.com/TefMeister/<repo>/archive/refs/heads/main.zip` (always the newest copy).

**For /sr:** add the same to this library's README, with the link
<https://github.com/TefMeister/flat-to-vr-cross-engine-research/archive/refs/heads/main.zip>, in the library's own
words. Lanes 0.93.0 also offers this library as an optional extra (`ours_cross_engine_library`).
